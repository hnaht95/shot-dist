# shot-dist

Bản cài và danh mục cập nhật (appcast) của **Shot** — app chụp màn hình cho macOS.

Mã nguồn nằm ở kho riêng tư; ở đây chỉ có thứ người dùng cần tải.

- **Tải về:** xem mục [Releases](https://github.com/hnaht95/shot-dist/releases).
- **Tự cập nhật:** Shot đọc `appcast.xml` ở https://hnaht95.github.io/shot-dist/appcast.xml.

Danh mục do `Scripts/release.sh` bên kho mã nguồn dựng và đẩy lên, mỗi bản một lần.
